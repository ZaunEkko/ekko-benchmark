# ADR-0007：S 级保留给核心链路完整的高完备度协议

## 状态

部分被 ADR-0008 取代。S/A 的分数区间仍有效，核心门槛条件不再有效。

## 背景

原等级只有 A 到 F，90-100 全部归为 A，无法区分“主流程完整但仍有明显辅助缺口”和“核心链路完整且整体协议接近完备”。如果只按加权原始分增加 S，又会允许核心能力缺失的项目凭辅助项进入最高等级。

## 决策

- 增加 S 级，范围为门槛后的最终分 95-100；
- A 级调整为 90-94.9，B 到 F 的边界保持不变；
- S 使用最终 `score` 而不是 `weightedScore`；
- 全部 17 条核心软件交付规则必须为 `pass`，门槛状态为 `clear`，才可能进入 S；
- 静态评分与 Agent 语义评分使用同一等级边界。

## 影响

- `limited` 最高仍为 B，`blocked` 最高仍为 D；
- S 表示静态协作协议的卓越完备度，不表示代码质量、模型能力或真实任务成功率；
- JSON Schema 和 TypeScript 报告契约新增 `S` 枚举值。
