# ADR-0001：静态协议完备度与工作流效果分开报告

## 状态

已接受。

## 背景

软件仓库中的 Agent 入口、协作协议、代码事实源和验证说明可以通过静态分析确定，但这些证据不能证明 AI 在真实开发任务中的代码正确率、安全性或恢复能力。把两类证据合成一个看似精确的分数，会掩盖指标含义并诱导错误比较。

## 决策

Ekko Benchmark 固定输出两个平行结果：

- 软件项目的静态需求协作协议完备度使用确定性离线规则评分；
- 工作流效果使用固定软件任务、运行记录和验收指标评分。

产品不自动把两层结果合成为单一总分，也不从静态分数推断实际效果。成本指标与质量指标分开报告。

## 影响

- 一行静态扫描可以独立使用，不要求真实跑软件任务，但报告必须带有解释边界；
- 对工作流效果的主张必须提供真实试验记录；
- 两层可以分别演进版本和 schema；
- 校准样本用于发现误报，不作为预设分数标签。
