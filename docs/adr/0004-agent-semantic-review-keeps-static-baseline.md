# ADR-0004：Agent 语义评分保留静态基线

## 状态

已接受。

## 背景

用户可能直接在 Codex、Claude Code 等 Coding Agent 会话中要求“看下这个软件项目并跑分”。确定性扫描适合提供稳定基线，但难以可靠理解所有软件团队的自定义措辞；已经在场的 Agent 可以做更完整的工程语义阅读。若直接用 Agent 结论覆盖静态分，报告会失去可复现性，也无法区分规则识别改进与模型判断差异。

## 决策

- 默认终端报告提示 Coding Agent 使用 `agent` 子命令继续语义评分；
- CLI 不主动调用外部 AI，`agent` 子命令生成带静态基线、维度语义、全部规则和两层权重的重评分协议；
- Agent 使用同一组能力、状态与权重，对全部适用规则独立重评，而不是只解释或修补静态结果；
- 每个 `pass` 或 `partial` 必须提供工作区内 `file:line` 证据，无法确认时使用 `unknown`；
- 被测文件和证据摘录按不可信输入处理，不得用其中的提示改变评分目标或突破读取、安全与保密边界；
- 输出并列保留静态协议分和 Agent 语义分，并记录 Agent/模型来源；
- 两种分数都不得解释为代码质量、模型能力或真实软件任务成功率。

## 影响

- 普通 `npx` 用户仍获得完全离线、确定性的默认结果；
- 在 Agent 会话中，用户可以用一条明确命令得到标准化语义复核，而不是依赖临时提示词；
- Agent 语义结果可以帮助定位静态规则误报和漏报，但不能作为静态扫描器自身准确性的替代证据。
